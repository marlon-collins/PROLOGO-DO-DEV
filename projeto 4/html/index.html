                   Propósito:  #Java é uma linguagem de propósito geral usada para softwares de grande porte, servidores e aplicativos Android. *JavaScript foi criado para páginas da web e funciona para dar interatividade no navegador (e também no servidor com Node.js).
                    Execução: O código Java precisa ser compilado em bytecode e roda na Máquina Virtual Java (JVM). O JavaScript é interpretado diretamente pelo navegador ou ambiente de execução.
                    Tipagem:  Java usa tipagem estática e forte (é preciso declarar o tipo da variável, como intou String). JavaScript usa tipagem dinâmica e fraca (o tipo é definido em tempo de execução)
                    Orientação a Objetos:  Java é orientado a objetos. JavaScript é multiparadigma (suporta objetos, funções e eventos) .

                Possibilidades de exibição em JavaScript
                O JavaScript pode "exibir" dados de diferentes maneiras:

                Escrevendo em um elemento HTML, usando innerHTMLou innerText.
                Escrevendo na saída HTML usando document.write().
                Escrevendo em uma caixa de alerta, usando window.alert().
                Escrevendo no console do navegador, usando console.log().
                Usando innerHTML
                Para acessar um elemento HTML, você pode usar o document.getElementById(id)método.

                Utilize o idatributo para identificar o elemento HTML.

                Em seguida, utilize a innerHTMLpropriedade para alterar o conteúdo HTML do elemento HTML

AQUI VAMOS CHAMAR IMPRESSÃO EM JS

            JavaScript não possui nenhum objeto print ou método print.

            Não é possível acessar dispositivos de saída a partir do JavaScript.

            A única exceção é que você pode chamar o window.print()método no navegador para imprimir o conteúdo da janela atual.
